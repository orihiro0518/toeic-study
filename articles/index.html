TOEIC対策ガイド

問題演習だけで終わらせず、「なぜその答えになるか」を整理するための無料ガイドです。Part 5・単語・熟語・文法を分野別に学べます。

Part 5対策

空欄の前後から品詞・時制・接続詞などを見抜く手順を整理。

TOEIC頻出単語

単語を日本語訳だけでなく、よく出る組み合わせと一緒に覚える方法。

TOEIC頻出熟語

前置詞句・定型表現をひとかたまりで覚えるポイント。

TOEIC英文法

品詞、時制、前置詞、接続詞、分詞、関係詞などの頻出論点を整理。

時制問題

現在完了・過去形・過去完了・未来表現を時間語句から見分ける。

品詞問題

名詞・形容詞・副詞・動詞を空欄前後の役割から判断。

接続詞問題

although / because / if と前置詞の違いを整理。

受動態

be＋過去分詞と、助動詞を含む受動態の見抜き方。

主語と動詞の一致

The number of、Neither、Eachなどの単数・複数判定。

比較表現

比較級・最上級・as ... asの頻出パターンを整理。

前置詞

前置詞と接続詞の違い、TOEIC頻出の前置詞表現。

分詞

現在分詞と過去分詞を「する側・される側」で見分ける。

関係詞

who・which・whoseなどを先行詞と文の欠けから判断。

覚えたら問題で確認

ガイドで整理した知識は、ORIVECTORの4択問題でそのまま確認できます。

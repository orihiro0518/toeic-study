📘 TOEIC文法 基礎解説

1. 品詞問題：空欄の「役割」を見る

意味を全部訳す前に、空欄の前後から必要な品詞を判断します。

冠詞 + 形容詞 + 名詞 ／ be動詞 + 形容詞 ／ 動詞を修飾 → 副詞

例：The new system operates efficiently. 「operates（動詞）」を修飾するので副詞。

語尾の目安：-tion/-ment は名詞、-ive/-al は形容詞、-ly は副詞が多い。

2. 時制：時間を表す語を先に探す

yesterday / last week は過去、since / for と現在までの継続なら現在完了、by the time + 過去なら過去完了が候補です。

have + 過去分詞 = 現在完了 ／ had + 過去分詞 = 過去完了
未来の予定でも when / if 節の中は現在形になることが多い。

3. 主語と動詞の一致

動詞の直前だけでなく、本当の主語を探します。前置詞句の中の名詞に引っ張られないことが重要です。

The list of items is ... （主語は list）
each / every / either / neither は基本的に単数扱い。

4. 接続詞と前置詞

後ろが「主語 + 動詞」なら接続詞、名詞だけなら前置詞を選ぶのが基本です。

because + S + V ／ because of + 名詞

although + S + V、despite / in spite of + 名詞、during + 名詞、while + S + V。

5. 関係詞

先行詞が人なら who、物なら which、所有なら whose。後ろの文に主語や目的語が欠けているかを確認します。

the employee who joined us ／ the device which we purchased
where は場所、when は時を表し、後ろに完全文が続く。

6. 分詞：-ing と -ed の見分け

名詞が「〜させる側」なら現在分詞、名詞が「〜される側・感じる側」なら過去分詞が基本です。

an exciting presentation ／ excited attendees
人の感情は interested / satisfied / pleased など -ed が頻出。

7. 不定詞と動名詞

動詞によって後ろに to do を取るか doing を取るかが決まります。

decide / plan / hope + to do ／ enjoy / avoid / consider + doing
look forward to の to は前置詞なので、後ろは doing。

8. 比較

than があれば比較級、the + 最上級、as ... as などの形を覚えます。

more efficient than ／ the most efficient ／ as soon as possible

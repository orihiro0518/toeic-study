TOEIC主語と動詞の一致

公開日：2026-09-02 ｜ 更新日：2026-09-03

主語と動詞の一致では、動詞の直前にある名詞に引っ張られず、本当の主語を見抜くことが重要です。

頻出ポイント

The number of + 複数名詞 の主語は number なので単数扱い。A number of + 複数名詞 は「多くの〜」で複数扱いです。Neither / Each / Every も基本的に単数扱いです。

主語の探し方

前置詞句や修飾部分をいったん外して、文の骨格だけを見ます。長い主語でも中心語が単数なら、動詞も単数形に合わせます。

例題

The number of online orders _____ increased dramatically this quarter.
答え：has
orders ではなく The number が主語なので単数扱いです。
「近くの名詞」ではなく「主語の中心語」を見るクセをつけると安定します。
